Little project to control some traffic lights using a Raspberry Pi Pico and some Google Gemini API calls.

This code exists as a directory of C/C++ files, which are then compiled to create the uf2 to be downloaded to the Raspberry Pi Pico.
When it is running, it can be communicated with using the various python scripts existing in the same directory.

Running `python gui.py` makes the multi-threaded GUI with AI integrations appear. This GUI was designed on Ubuntu, so running in that environment may yield the best viewing results.
